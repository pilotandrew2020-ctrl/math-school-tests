# math-school-tests

Автономный интерактивный портал «Геометрия», оптимизированный под iPad (Safari). Работает как статический сайт на Vercel: **никаких внешних скриптов, шрифтов, CDN, iframe и сетевых запросов** — всё лежит в репозитории.

## Вкладки

| Вкладка | Что внутри |
|---|---|
| Геометрия (Главная) | 3D-многогранники на Three.js (с CSS-запасным вариантом без WebGL), теорема Пифагора, графики функций, единичная окружность, калькулятор окружности/шара, опорные формулы |
| Игровой блок: Тетрис | Полноценный Тетрис на Canvas: 7-bag, запас, призрак, lock delay, уровни, рекорд (localStorage). Клавиатура, экранные кнопки, свайпы |
| Игровой блок: Змейка | Змейка на Canvas: очки, рекорд, бонус-звезда, режимы «Стены» / «Без стен», плавная анимация. Клавиатура, свайпы, крестовина |
| Медиа-плеер | Вертикальный `<video>`-плеер (9:16): 5 локальных MP4/WebM-клипов, локальный HLS-поток (`.m3u8`, нативно в Safari), «живой» поток из `canvas.captureStream()`. Тап — пауза, двойной тап — лайк, свайп вверх/вниз — смена ролика, перемотка, звук, повтор, полный экран |

Код игр и логика вкладок встроены прямо в `index.html`. Вне HTML лежат только скомпилированные ресурсы:

- `assets/tailwind.css` — Tailwind CSS 3, собран локально и минифицирован;
- `assets/geometry3d.js` — Three.js + код 3D-сцены одним файлом (IIFE);
- `media/` — видеоклипы, постеры и HLS-поток.

## Сборка ресурсов (не нужна для деплоя)

Vercel отдаёт репозиторий как есть (сборка не требуется). Если нужно изменить стили, 3D-сцену или видео — исходники в `tools/`:

```bash
cd tools && ./build.sh      # Tailwind -> assets/tailwind.css, Three.js -> assets/geometry3d.js
./tools/make-media.sh       # из корня: пересоздать клипы/постеры/HLS через ffmpeg
```

Классы Tailwind берутся из `index.html`, поэтому после правки разметки пересоберите CSS.

## Совместимость

Рассчитано на iPadOS 15+ (Safari): `playsinline`-видео, pointer events, `dvh` с запасным `vh`, safe-area. Клипы кодированы H.264/AAC (+ WebM для остальных браузеров).
